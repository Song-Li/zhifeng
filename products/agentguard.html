核心能力

七大安全控制能力

身份与权限控制

Agent 身份管理、最小权限策略、分级授权、高风险操作二次确认、按任务和上下文动态授权。

工具调用安全

调用前风险判断、工具描述可信校验、参数检查、白名单/黑名单策略、高危调用阻断或转人工审批。

Prompt 注入防护

Prompt 注入检测、间接注入识别、外部文档中的恶意指令识别、上下文污染检测、系统指令边界保护。

数据访问保护

敏感数据识别、访问策略控制、数据脱敏与隐藏、防外传检查、外部模型调用前数据风险检查。

行为监控与审计

操作链路记录、工具调用日志、数据访问轨迹、决策过程审计、异常行为检测、事后追溯与合规报告。

沙箱与隔离执行

高风险任务沙箱执行、工具隔离、网络访问限制、文件访问限制、命令执行限制、回滚与补救机制。

多 Agent 协作治理

多 Agent 任务流编排安全、权限边界控制、跨 Agent 数据传递审计、任务责任链追踪、协作过程风险识别。
